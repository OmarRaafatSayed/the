# Mashrabiya Heritage

A high-end digital archive and scientific repository dedicated to the restoration and characterization of archaeological Mashrabiya units.

## Project Overview
This project focuses on the forensic documentation of 12th-century Cairene lattice windows. It bridges historical craftsmanship with modern digital preservation ethics through:
- **Phase I: Documentation**: Historical context, structural anatomy, and morphological analysis.
- **Interactive Visualization**: Before-and-after restoration comparisons and Macro-to-Micro interactive scanning.
- **AI Integration**: Cultural and historical context generation for architectural patterns.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS with a "Vintage-Modern" aesthetic.
- **Components**: Radix UI / ShadCN.
- **AI**: Genkit for architectural history synthesis.

## Visual Identity
The project utilizes a strictly curated palette:
- **Background**: Deep Cream (#EBE3D5)
- **Accent**: Burnt Orange / Terracotta (#D35400)
- **Contrast**: Charcoal Black (#1A1A1A)

Developed as a scientific consortium project.
